# Contributing

**Issues only — code contributions aren't being accepted.**

Corrections, bug reports and suggestions are welcome and are the fastest way to make the game
better. Please open an issue.

Pull requests will be closed. That isn't unfriendliness: accepting code means the contributor
retains copyright in their work, which complicates the licensing of a project that may become
commercial. Rather than run a contributor agreement for a project this size, the code stays
mine and the conversation stays open.

## Reporting a wrong number

Include the player, the stat, the correct value, and a source. Every figure in the deck carries
its own source and check date, so a cited correction can be verified and applied quickly.

Corrections take effect at the next daily rollover, never mid-game.
